# Rajlaxmi Mishra - Portfolio

A personal portfolio website for Rajlaxmi Mishra, a Computer Science student at Indus University. The site presents selected projects, technical skills, education, and contact links.

## Built with

- HTML
- CSS
- Vanilla JavaScript modules
- Bootstrap 5.3 for layout utilities and the offcanvas menu

## Run locally

The project has no build step or package installation.

1. Clone this repository.
2. Open `index.html` in a browser, or serve the project folder locally:

   ```powershell
   py -m http.server 8000
   ```

3. Visit `http://localhost:8000`.
